## Carelio — Minnesota Community Needs Analytics

Carelio is a county-level analytics and decision-support tool covering all **87 Minnesota counties**.

The project combines food-access, health, insurance, income, population, school-lunch, and community-resource data to help identify areas with higher levels of need.

### Features

* County-level analysis
* Food-need indicators
* Health-risk indicators
* Priority scoring
* KPI cards
* Interactive filters
* County comparisons
* Community-resource visibility
* Plain-language explanations for non-technical users

Carelio provided the analytical foundation for the development of **Carelio Connect**.
